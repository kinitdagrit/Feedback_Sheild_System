# Feedback Shield

Comment checker (English, Tagalog, Bisaya) nga mo-save sa Supabase.
Static website (GitHub Pages), walay PHP.

## Setup
1. Himoa ang Supabase project, i-run ang `supabase.sql` sa SQL Editor.
2. I-edit ang `config.js` (Project URL + publishable key).
3. GitHub: Settings -> Pages -> Deploy from a branch -> main / (root).

Ang daan nga XAMPP/PHP nga bersyon naa sa `xampp-version/`.
